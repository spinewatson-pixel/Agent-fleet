# GOV-CHAIR Decision — Agent Ceiling

**Decision ID:** GOV-CEIL-2026-07-28  
**Seats:** GOV-CHAIR, HUMAN-1, LIFE-1, ARCH-1  
**Status:** Adopted

## Finding

Registry roster is **279 agents** vs prior ceiling **150**. The excess is intentional Watchfloor lab design (paired specialists, scouts, novel fleet, quant wing, fund desks) — not uncontrolled agent spawning.

## Decision

**Raise `hard_rules.agent_ceiling` from 150 → 300** with conditions:

1. New agents still require GOV-CHAIR proposal + COMP-1 mandate check.
2. UI custom-agent creation must not bypass ceiling checks (P1 enforcement).
3. Cohort status may still be marked ON-DEMAND / RETIRED by LIFE-1 without deleting history.
4. Ceiling raises above 300 require a fresh HUMAN-1 authorization artifact.

## Rejected alternative

Pruning active paper cohorts to ≤150 would break the Watchfloor UI org chart and destroy comparable cohort experiments the lab exists to run.

## Artifacts

- `config/watchfloor_registry.json` → `hard_rules.agent_ceiling: 300`
- `config/organization.yaml` → `agent_ceiling: 300`
