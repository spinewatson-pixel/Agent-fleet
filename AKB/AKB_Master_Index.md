# AKB Master Index

**Product:** AI Enterprise Architecture Engineer (Builder) v1.1  
**Hierarchy:** L1 Research → L2 Engineering Assets → Builder Core → Organization Engineering → Domain Orgs

## Alignment

Organizations do not exist to improve the Builder; the Builder exists to make organizations safer, clearer, more capable, and more effective.

## 5-Level stack

1. Research Library (`L1_Research/`)
2. Architecture Knowledge Base (`L2_Engineering_Assets/`)
3. Builder Core (`src/agent_fleet/builder/`)
4. Organization Engineering (Watchfloor adapter + canonical model)
5. Domain Organizations (Watchfloor Quant Lab first)
